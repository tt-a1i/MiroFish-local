# 详细人设背景关键标签弹窗内容规范

## 1. 背景与目标

当前 Step2「详细人设背景」的四个标签曾直接复用整段 persona 文本，导致「事件全景经历」「行为模式侧写」「独特记忆印记」「社会关系网络」四类内容货不对板。后续恢复弹窗功能前，必须先把每个标签的语义、数据边界和展示结构固定下来。

核心目标：

- 标签弹窗只展示与该标签对应的信息，不再整段复制人设详情。
- 内容必须绑定当前人设 agent 的主体，不能把相关机构、媒体、警方或其他节点的信息套到个人账号上。
- 事实性内容必须来自图谱关系、真实资料核验结果或模拟运行记忆；推断性内容必须明确标注为「行为侧写」或「经验总结」。
- 当数据不足时展示「暂无足够数据」，不能用 LLM 补写成看似确定的事实。

## 2. 主体一致性底线

弹窗内容生成前必须先确认当前 agent 主体：

- `profile.name` 是现实主体名称，例如「许国利」。
- `profile.username` 是平台账号 handle，例如 `xuguoli_179`。
- `source_entity_uuid` 必须指向同一个图谱实体。
- `provenance.verification_status` 为 `verified` 时，事实内容优先使用 `real_identity_summary`、`verified_facts`、`source_citations`。
- 若当前 agent 是个人，弹窗内容不得以「公安机关」「分局」「官方发布平台」「机构正式名称」等机构主体开头。

错误示例：

```text
许国利 / @xuguoli_179 的「事件全景经历」显示：
机构正式名称：杭州市公安局江干区分局……
```

正确处理：

```text
许国利 / @xuguoli_179 的「事件全景经历」只能展示许国利本人
在杭州杀妻案中的身份、公开行为轨迹、司法节点和事件影响。
公安机关信息只可作为社会关系网络中的「执法/调查节点」出现。
```

## 3. 四个标签的正确内容定义

### 3.1 事件全景经历

定义：当前 agent 在此现实事件中的完整行为轨迹。

应展示内容：

- 事件中的身份：当事人、被告人、受害者、调查机构、媒体、家属等。
- 时间线：按真实事件节点排序。
- 行为轨迹：公开报道或图谱关系中能支持的动作、决策、回应、参与过程。
- 结果节点：立案、侦查、发布会、审判、判决、执行、后续影响等。
- 事实来源：可引用来源标题或图谱事实摘要。

不应展示内容：

- 普通人物背景、性格描述、MBTI。
- 机构职责说明，除非当前 agent 本身就是机构。
- 与事件无关的履历。

推荐结构：

```text
身份定位：
许国利是杭州杀妻案中的案发当事人/被告人。

事件时间线：
1. 2020-07-05：来惠利失踪报案相关节点出现。
2. 2020-07-22：警方锁定许国利有重大作案嫌疑。
3. 2021-05-14：一审宣判死刑。
4. 2023-03-21：依法执行死刑。

行为轨迹：
围绕公开报道和图谱关系，概括其在事件中的关键行为与司法过程。

来源依据：
列出图谱关系或真实资料来源摘要。
```

### 3.2 行为模式侧写

定义：当前 agent 基于事件暴露出的经验总结、行事风格偏好和模拟交互中的行为倾向。

应展示内容：

- 事件中呈现的决策方式、风险偏好、信息表达习惯。
- 在模拟舆论场中的可能互动风格：沉默、防御、回避、强硬回应、官方克制等。
- 行为触发条件：哪些话题会让该 agent 更可能发言、回避或改变立场。
- 可解释的经验总结：基于事实和图谱关系的概括。

不应展示内容：

- 不能把推断写成真实事实。
- 不能凭空生成心理诊断。
- 不能把机构口径写到个人身上。

推荐结构：

```text
行为侧写结论：
基于已知事件轨迹，该 agent 在模拟中应呈现……

行事风格：
- 信息处理：
- 互动偏好：
- 情绪/风险反应：

触发条件：
- 被直接追问事件责任时……
- 面对司法程序讨论时……

边界说明：
以上为模拟行为侧写，不等同于新增现实事实。
```

### 3.3 独特记忆印记

定义：当前 agent 基于现实事件形成的记忆，也可以是图谱中的记忆链。

应展示内容：

- 与当前 agent 直接相关的事件记忆节点。
- 图谱中的关系链：`主体 -> 行为/关系 -> 对象/事件 -> 后果`。
- 对后续模拟发言有影响的记忆片段。
- 记忆强度或稳定性：核心记忆、次级记忆、待核验记忆。

不应展示内容：

- 整段 persona。
- 泛泛的「喜欢什么」「MBTI」。
- 没有来源的内心独白。

推荐结构：

```text
核心记忆：
许国利与杭州杀妻案司法过程直接绑定，是其模拟身份不可移除的核心记忆。

记忆链：
许国利 -> 涉及杭州杀妻案 -> 被侦查/起诉/审判 -> 一审死刑/执行死刑。

对模拟行为的影响：
该记忆会影响其面对案件追问、司法讨论、公共舆论评价时的回应边界。

数据状态：
已核验 / 来自图谱 / 待核验。
```

### 3.4 社会关系网络

定义：当前 agent 的个体链接与交互图谱。

应展示内容：

- 与当前 agent 相连的人、机构、媒体、司法节点、事件节点。
- 每条关系的方向、类型和事实摘要。
- 关系强度或关系类别：亲属、涉案、调查、审判、报道、舆论互动等。
- 可以展示小型关系列表或后续图谱可视化。

不应展示内容：

- 把相邻机构的完整人设复制进来。
- 把事件话题标签当成社会关系。
- 展示与当前 agent 无关的全局图谱。

推荐结构：

```text
核心关系：
- 来惠利：受害者/亲属关系，案件核心关联人。
- 公安机关：调查与侦查节点，负责案件侦办。
- 法院：审判与判决节点。
- 新闻媒体：报道与舆论传播节点。

关系链摘要：
许国利 -> 杭州杀妻案 -> 公安机关侦查 -> 法院审判 -> 媒体报道/公众讨论。

交互边界：
机构节点只作为关系对象出现，不替代许国利本人的身份详情。
```

## 4. 数据来源优先级

弹窗内容应按以下优先级取数：

1. `provenance.verified_facts` 与 `real_identity_summary`：真实资料核验结果。
2. 图谱实体自身字段：`summary`、`attributes`。
3. 图谱关系：`related_edges`、`related_nodes`。
4. 模拟运行记忆：actions、comments、interviews、graph memory replay。
5. LLM 摘要：只能用于组织语言，不能新增无来源事实。

## 5. 内容生成规则

- 每个标签对应独立字段，例如 `persona_background.event_journey`、`behavior_profile`、`memory_signature`、`social_network`。
- 后端生成结构化 JSON，前端只负责展示，不在前端用正则从 persona 大段文本里硬拆。
- 每个字段都要返回 `content`、`evidence`、`confidence`、`empty_reason`。
- 证据不足时返回空内容和原因，不生成拟真文本。

建议结构：

```json
{
  "persona_background": {
    "event_journey": {
      "content": "...",
      "evidence": [{"type": "verified_fact", "text": "...", "source": "..."}],
      "confidence": "high",
      "empty_reason": ""
    },
    "behavior_profile": {
      "content": "...",
      "evidence": [{"type": "inference", "text": "由事件行为轨迹概括"}],
      "confidence": "medium",
      "empty_reason": ""
    },
    "memory_signature": {
      "content": "...",
      "evidence": [{"type": "graph_edge", "text": "..."}],
      "confidence": "high",
      "empty_reason": ""
    },
    "social_network": {
      "content": "...",
      "evidence": [{"type": "graph_relation", "text": "..."}],
      "confidence": "high",
      "empty_reason": ""
    }
  }
}
```

## 6. 前端展示建议

恢复功能时建议：

- 四个标签可点击，但弹窗标题必须与标签一致。
- 弹窗正文只展示该标签字段，不展示完整 persona。
- 展示「事实依据」折叠区，列出来源摘要。
- 对行为侧写类内容标注「模拟侧写，不代表新增事实」。
- 若字段为空，显示空态：`暂无足够的图谱关系或核验事实支撑该内容。`

## 7. 验收标准

- 点击「事件全景经历」只看到当前 agent 的事件轨迹。
- 点击「行为模式侧写」只看到行为偏好、互动风格和触发条件。
- 点击「独特记忆印记」只看到事件记忆和图谱记忆链。
- 点击「社会关系网络」只看到当前 agent 的关系节点和交互图谱。
- 对 `许国利 / @xuguoli_*`，任何标签都不得把其详情主体展示为公安机关。
- 当数据不足时不弹出伪造详情。
