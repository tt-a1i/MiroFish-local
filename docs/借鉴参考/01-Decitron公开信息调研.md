## 产品定位

公开资料将 Decitron 定位为“面向复杂系统的 AI 决策引擎”，核心目标是构建从信号感知到未来推演的决策闭环。它强调的不是回答一个问题，而是将复杂现实问题转化为可模拟、可验证、可优化的决策空间。

官网与公众号中反复出现的能力关键词包括：

- 全球信号感知
- 事件链重建
- 核心变量抽取
- 多智能体博弈模拟
- 关键变化感知
- 方案量化评估
- 时序演化推演
- 多情景仿真
- 世界建模
- 概率信念建模与贝叶斯更新
- 因果与概率推断
- 复杂情景仿真

这些关键词对应的产品逻辑可以抽象成：

```text
外部信号 -> 事件链/变量结构化 -> 决策场景建模 -> 多主体/多路径推演
        -> 方案评估 -> 概率/风险更新 -> 持续追踪 -> 决策报告
```

## 官网能力拆解

### 1. 从信号到事件链

官网页面强调“感知全球信号，理解关键问题，构建决策场景”。这说明 Decitron 的第一层能力不是生成答案，而是先从政策、市场、产业、舆情等外部变化中识别对决策真正有用的信号。

可拆成三个工程能力：

- 信号摄取：持续收集新闻、政策、市场、舆情、行业动态等外部信息。
- 事件链重建：把碎片信息按时间序列还原成事件链。
- 变量抽取：识别驱动事件变化的关键因素、约束和隐含机制。

对 MiroFish-local 的启发是：当前 Step1 已有一次性联网搜索和资料摘要，但还没有“持续信号订阅、信号版本、信号阈值、信号触发推演更新”。这正是短中期最值得补的能力。

### 2. 从事件到决策场景

Decitron 公开资料中多次提到“构建现实世界的可计算模型”“把复杂现实问题转化为可推演系统”。这意味着它不是直接让大模型写结论，而是需要一个中间层，把现实问题结构化成可推演对象。

可抽象为：

| 结构 | 含义 |
| --- | --- |
| State | 当前事件状态、传播状态、市场状态或治理状态 |
| Actor | 国家、企业、公众、媒体、监管者、平台、投资人等主体 |
| Action | 主体可采取的行动或策略 |
| Constraint | 资源、规则、政策、时间、舆论、成本等约束 |
| Outcome | 可能结果、风险、收益、传播影响、概率变化 |
| Signal | 影响路径切换和概率更新的外部观测 |

这与 MiroFish-local 现有的 `simulation_requirement`、实体图谱、人设 Agent、平台配置和行动日志高度相容，但当前还缺少统一的决策结构对象。

### 3. 多路径与多角色博弈

官网强调“多路径与多角色博弈中推演未来”，公众号也强调多主体目标、约束、偏好和行动空间。它背后的产品表达不是单条预测，而是多个可能世界的比较。

工程上至少需要：

- 情景 A/B/C 定义
- 每个情景的初始条件和干预策略
- 多次仿真结果聚合
- 关键路径、拐点、分歧变量对比
- 指标化评估

MiroFish-local 当前支持重新推演，但没有情景分支、分支快照和多报告横向对比。后续应优先做成“同一个项目下的多情景中心”。

### 4. 方案量化评估

官网明确强调对不同路径的收益、风险与成功概率进行系统评估。公众号中也提到比较概率、追踪信号和校准判断。

这与普通报告的区别在于：

- 普通报告：描述发生了什么、可能会怎样。
- 决策报告：比较不同方案在指标上的差异，说明为什么选择方案 A 而不是方案 B。

对传播推演场景，可量化指标包括：

- 传播峰值时间
- 负面情绪占比
- 二次传播峰概率
- 关键节点扩散速度
- 官方回应滞后成本
- 谣言/反转风险
- 平台放大系数
- 核心群体态度变化
- 干预后风险下降幅度

## 公众号发布稿信息

公众号文章标题为“中科闻歌重磅发布通用决策大模型Decitron决策机，内测邀请开启”，发布时间戳对应 2026-06-05 11:00 北京时间。

### 三大功能

公众号将 Decitron 的功能概括为三项：

1. 决策推演：识别问题边界、时间范围、判断对象、核心变量和关键主体，将复杂问题转为可推演结构。
2. X-Signal 全球信号：持续监测新闻、政策、市场信号和关键变量变化，并在原有推演结构上更新路径和概率。
3. 市场预测：引入外部概率共识网络，解释概率变化背后的因果机制和信号驱动。

### 三条关键技术路径

公众号提到三项技术路径：

1. 世界模型：把新闻、政策、事件、市场信号等转化为 State-Action-Outcome 框架。
2. 多智能体推演：对不同主体建模，模拟主体目标、约束、资源、偏好和行动空间。
3. 博弈求解：结合大模型理解、因果推断、概率更新、策略均衡和路径优化。

### 测评信息

公众号声称 Decitron 在 PolyBench 数据集上达到如下指标：

- 终局预测准确率 FFA：81.20%
- 预期波动预测准确率 EVPA：73.40%
- 平均概率预测偏差 MSE：0.822%

注意：公开文章未给出完整数据集定义、样本规模、评测方法、基线模型、复现实验和误差分析。因此这些指标只适合作为“官方能力声明”，不宜直接作为 MiroFish-local 需求中的验证目标。

### 演示案例

公众号展示的案例包括：

- 金融领域：2026 年美联储是否降息
- 国际形势：霍尔木兹海峡通行恢复
- 企业战略：TikTok 东南亚电商独立融资
- 产业趋势：短剧行业发展

官网页面还将应用场景扩展到金融、企业战略、地缘政治、舆情事件等。其中“舆情事件推演”与 MiroFish-local 当前定位最接近。

## 可借鉴的抽象模型

综合官网和公众号，可以把 Decitron 的可借鉴模型归纳为五层：

```text
1. Signal Layer
   外部信号、内部仿真日志、用户补充材料、平台数据

2. Scenario Layer
   决策问题、主体、变量、时间范围、约束、干预方案

3. Simulation Layer
   多主体行为、多路径演化、平行世界、时序推演

4. Evaluation Layer
   结果指标、概率区间、风险等级、方案收益、关键拐点

5. Report & Feedback Layer
   决策报告、可观察信号、复盘、概率更新、再推演
```

MiroFish-local 当前已经覆盖第 2 层和第 3 层的一部分，第 1 层有一次性输入，第 4 层和第 5 层较弱。后续升级重点应落在 Signal、Evaluation、Feedback 三层。

## 对 MiroFish-local 的核心启发

1. 传播推演不应只回答“舆论会怎么发展”，还要回答“什么条件会导致哪条路径发生”。
2. 报告不应只写趋势，还要输出指标、置信度、触发信号、策略建议和待观察变量。
3. 多次推演不应只是重新运行，而应成为可命名、可比较、可复盘的情景分支。
4. 外部搜索不应只发生在 Step1，而应成为推演后的持续信号追踪能力。
5. 图谱记忆不应只记录模拟动作，也应记录外部信号、假设变化和概率更新。
