## 核心结论

MiroFish-local 与 Decitron 的方向高度同频，但定位层级不同：

- Decitron 的公开叙事是“面向复杂系统的通用决策推演系统”，强调全球信号、世界建模、多智能体博弈、概率建模、多情景仿真、方案量化评估与持续追踪。
- MiroFish-local 当前是“传播推演专用流水线”，已具备图谱构建、Agent 人设、OASIS 双平台社交仿真、行动日志、图谱记忆写回、报告 Agent 和深度互动能力。
- 最值得借鉴的不是“通用决策大模型”的宏大表述，而是把 MiroFish-local 从“单次传播模拟 + 叙述型报告”升级为“结构化决策问题 + 多情景对比 + 指标评估 + 外部信号追踪 + 概率校准 + 决策型报告”。

## 推荐升级方向

短期先做三件事：

1. 在 Step1 引入“决策问题结构化”，把用户输入拆成判断对象、时间范围、关键主体、核心变量、可干预策略、目标指标。
2. 在 Step2 引入“情景/策略配置”，支持多个传播干预方案的配置、保存和复用。
3. 在 Step4 把报告升级为“决策型报告”，固定输出核心判断、关键变量、路径假设、风险信号、行动建议和待观察信号。

中期形成闭环：

1. 支持多情景并行或批量运行，并生成横向对比报告。
2. 建立基于 actions.jsonl 和图谱记忆的指标评估服务。
3. 接入外部信号追踪，把搜索结果、新闻更新、用户补充材料写成 signal episode。

长期再扩展：

1. 建立概率信念更新和回测校准体系。
2. 抽象 OASIS 外的环境适配器，让传播推演能力向更广泛复杂决策场景扩展。
3. 形成“传播推演决策引擎”的产品体系，而不是简单追随通用决策机叙事。
